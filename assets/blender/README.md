# Blender source

Six original box-built low-poly oak/iron prototypes were generated and exported through the connected Blender MCP on 2026-09-08. The pre-existing Blender scene was preserved.

The isolated `Lantern_Lane_Assets` scene is saved in `furniture_prototypes.blend`. Parts remain separate editable meshes; the six models overlap at their shared export origin in this source scene. The GLBs in ../furniture each contain only the corresponding selected furniture parts.

The source directory has .gdignore so Godot runs from the GLBs and never requires Blender to import the project. No external assets, textures or licensing dependencies were used.
